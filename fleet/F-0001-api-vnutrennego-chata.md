## Цель
Понять, есть ли у внутреннего корпоративного чата API, позволяющий забирать переписку по каналам/тредам для саммари в `inbox/chats/`.

## Контекст и ссылки
- Чат — внутренняя **кастомная (самописная)** система, вендорской документации нет: разбираемся с нуля.
- Доступ только из корпоративной сети: выполнять с ноутбука.
- Результат нужен для автоматизации A8 (см. `AUTOMATION.md`).

## С чего начать исследование
- Клиент чата (веб/десктоп): перехватить HTTP-запросы, которые он делает (DevTools / прокси), — восстановить неофициальное API по фактическим вызовам.
- Найти команду, которая разрабатывает чат, и внутреннюю документацию: спросить про API и ботов напрямую — часто самый быстрый путь.
- Если API нет и не появится: экспорт из клиента, доступ к БД/логам сервиса, регламентный ручной дроп — сравнить по трудозатратам.

## Критерий готовности
Заметка в `integrations/` с ответами: есть ли API; как авторизоваться; какие endpoint'ы дают историю сообщений; ограничения и лимиты. Если API нет — 2–3 альтернативы (экспорт, бот, регламентный ручной дроп) с оценкой трудозатрат.
