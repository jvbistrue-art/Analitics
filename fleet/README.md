# Флот

Задачи для ИИ-агентов. Основной объём работы — на агентах; моё — отвечать на вопросы и принимать решения (`state: needs-me`).

## Жизненный цикл
```
inbox → queued → running → needs-me → done
                     └────→ cancelled
```

## Как завести задачу (в т.ч. с телефона)
1. Скопировать `_template-task.md` → `F-XXXX-короткое-имя.md` (следующий свободный номер).
2. Заполнить «Цель» и «Критерий готовности» — остальное агент допишет сам.
3. `state: queued`. Для cloud-задачи — запустить агента и вписать `run_url`.

## Правила
- Один `needs-me` = один конкретный вопрос. Агент не копит вопросы.
- `model: internal` — задачи про внутренние системы и данные; выполняются внутренней моделью с ноутбука (доступ в корпоративную сеть).
- Доска `FLEET.md` пересобирается агентом из файлов этой папки — руками её не правим.
