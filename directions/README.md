# Направления

Одна заметка состояния на направление — точка входа в контекст за 30 секунд. R&D-режим («гаражная разработка»): направления вместо фич, гипотезы и PoC живут внутри заметки.

- Создавать по шаблону `_template-direction.md`.
- Поля `jira_filter` и `confluence_space` связывают заметку с внешними системами: по ним агент собирает статус и публикует общекомандную документацию.
- Раздел «Победы и провалы недели» — прямой источник еженедельного статуса руководству; пополняется по итогам недели (агент предлагает, я подтверждаю).
- Статусы `green / yellow / red` сводятся в `DASHBOARD.md`.
