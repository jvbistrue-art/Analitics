# Клавиши — интерактивный учебник пианино

Веб-учебник на базе бесплатного курса **Online Piano University** (Dr. Maria Pisarenko): 41 урок **от простого к сложному**, разбитые на 8 модулей.

## Что внутри

- Русские конспекты всех 41 уроков (цели, теория, шаги, термины) — по транскриптам курса
- Встроенные YouTube-видео (не скачиваются — авторское право)
- Локальный каталог уроков + превью + сырые `.en.txt` транскрипты в `scripts/transcripts/`
- Интерактивная клавиатура (Web Audio)
- Мини-квизы и прогресс в `localStorage`

## Запуск

```bash
npm install
npm run dev
```
