Now it's time to talk about our new intervals. We have a seventh and an octave. An octave has another name — it's called an eighth. So you have the seventh and the eighth, or the seventh and the octave. And I will remind you again that an interval is the distance between two sounds. The distance can be a short distance or a long distance. All these intervals have different names, and we name them according to the English alphabet. So if we have two letter names in alphabetical order involved, this interval will be called a second. If you have three letter names involved in the interval — A, B, and C — the distance between A and C is a third. A, B, C, D — the distance between A and D is the fourth. A, B, C, D, E — the distance between A and E is a fifth. If you have A, B, C, D, E, F, the distance is going to be called the sixth, between A and F. Now you will have A, B, C, D, E, F, G — so you will have seven letter names in alphabetical order, so the distance between A and G is going to be called a seventh. So you can have A–G, or you can have C–B; you can start on any key. You just remember your letter names in alphabetical order. And another interval is an octave. So A, B, C, D, E, F, G — after G we go back to A again, because we have only seven notes, also represented by seven letters. So A, B, C, D, E, F, G, A. So the distance from A to A will be called an eighth, or an octave. Or C and C, or G and G, or E and E — so you will have the same letter one octave apart. This will be called an octave, or an eighth.
