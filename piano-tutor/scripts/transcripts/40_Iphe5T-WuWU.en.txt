Now it's time for us to look at another scale: the D minor scale. The D minor scale starts on D, and it is also a relative minor for the F major scale. Remember that every major scale has its relative minor. So if you go from F down one and a half steps — from F to D — you will find the relative minor for F. So it is D minor. So the scale is D, E, F, G, A, B flat, C, D. To make it harmonic, you raise C one half step. So the C note is the seventh key of the scale — to make it harmonic, you raise that seventh key of the scale and you put a sharp next to C. So D, E, F, G, A, B flat, C sharp, D.

Now it's time to talk about the primary chords in D minor. The primary chords are built on the first, fourth, and fifth key of the scale. So if you build a chord starting on D, you will get D F A, a chord built on the first key. If you start on the fourth key of the scale, which is G, you will have G B flat D chord. And if you start on the fifth key of the scale, which is A, you will have A C sharp E. Remember, we are using a harmonic minor — that's why we have C sharp. Now we can also make it a seventh chord if you add one more note here. The whole chord will have four notes — it will be a five-seven chord. So you will have a five-seven.
