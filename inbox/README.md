# Входящие

Сюда руками кладутся сырые источники; агент саммаризирует по шаблону `_template-summary.md` и раскладывает по контурам, после чего переносит файл в `processed/`.

| Подпапка | Что | Как попадает |
|---|---|---|
| `transcripts/` | транскрибации конфколов | сейчас вручную с веба; цель — автозабор (F-0002) |
| `mail/` | письма Outlook | вручную: скопировать письмо в файл |
| `chats/` | внутренний чат, Telegram | вручную; цель для чата — выгрузка по API (F-0001) |
| `processed/` | обработанное | переносит агент |

## Именование
`YYYY-MM-DD_источник_тема.md`, например `2026-08-06_confcall_sync-napravlenie-a.md`

## Разметка
Если в источнике обсуждаются люди или деньги — сразу при дропе добавить во frontmatter `sensitivity: internal`; обработка пойдёт только внутренней моделью.

## Результат обработки
Решения → заметка направления, экшены → задачи/флот, сигналы по людям → `people/`, цифры → `budget/`.
