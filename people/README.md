# Люди

Контур людей: команда, контакты, 1:1, развитие, повышения, командировки. Чувствительность — internal (см. `AGENTS.md` этой папки).

- `team.md` — состав моей и бизнес-команды.
- `contacts.md` — база контактов.
- На ключевых людей — отдельная заметка по шаблону `_template-person.md` (история 1:1, планы развития, повышения).
- `1on1/` — заметки встреч по шаблону `1on1/_template-1on1.md`; повестку к следующей встрече готовит агент (автоматизация A4).
