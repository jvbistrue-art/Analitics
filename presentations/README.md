# Презентации

## Подход
- Источник слайдов — markdown в этом хранилище: еженедельный статус — из `reporting/weekly/`, демо президенту — отдельная заметка на каждое мероприятие.
- Рендер: рабочая гипотеза — Marp (слайды из markdown, версионируются вместе с источником, дифы читаемы). Финальный формат и оформление определим после того, как я покажу примеры готовых презентаций.

## Еженедельный статус руководству
Гант по направлениям + победы и провалы недели. Собирается из `reporting/weekly/`.

## Демо президенту (ежемесячно)
Структура:
1. О чём PoC — простая картинка/история, понятная без контекста.
2. Живая демонстрация решения (чек-лист готовности: данные, окружение, запасной сценарий при падении).
3. Бизнес-выгода — блок готовит бизнес-команда, мне нужен плейсхолдер и контроль срока.
