# Analitics — Edge LLM Swarm

Исследование и прототип **вычислительного роя** из Android-устройств и одноплатников (Raspberry Pi и аналоги) для локального запуска LLM.

## Короткий ответ

Объединить можно. Память роя складывается (большая модель «влезает» через шардинг), скорость — почти нет: на Wi‑Fi каждый токен платит сеть. Практичный продукт — оркестратор с двумя режимами:

- **Replica / task parallel** — много узлов, каждая задача на своём воркере (основной режим для Wi‑Fi).
- **Shard / layer parallel** — одна большая модель по слоям через llama.cpp RPC (когда суммарной RAM хватает, а latency терпима).

Подробности: [docs/llm-swarm-architecture.md](docs/llm-swarm-architecture.md).
