# Рабочее пространство техлида

Личное хранилище для ведения всех дел: направления, люди, бюджет, отчётность, презентации, флот AI-задач. Obsidian + git — одинаково работает на ноутбуке и телефоне.

## Карта пространства
- `DASHBOARD.md` — полная картина на сейчас (пересобирается агентом, v0 — экспериментальный формат)
- `FLEET.md` + `fleet/` — очередь задач для ИИ; моё участие — только колонка «Ждёт меня»
- `directions/` — по одной заметке состояния на направление (вход в контекст за 30 секунд)
- `people/` — команда, контакты, 1:1 (internal)
- `budget/` — потребность на следующий год и оптимизация (internal)
- `reporting/` — ритуалы и заготовки регулярной отчётности
- `presentations/` — источники слайдов
- `inbox/` — сырые источники: транскрибации, письма, чаты
- `integrations/` — контракт интеграций (Jira, Confluence, внутренняя LLM и др.)
- `AUTOMATION.md` — roadmap автоматизаций

## Принципы
1. **Общий контекст без перемешивания.** Контуры разделены папками; правила обработки — в `AGENTS.md` (корневом и контурных).
2. **Система держит контекст за меня.** Я работаю стеком, по одной задаче; состояние всего остального хранится здесь и сводится в `DASHBOARD.md`.
3. **Рутину делает флот.** Чтение и сборку данных агенты делают автоматически; запись во внешние системы — только по моей команде.
4. **Чувствительное не уходит наружу.** `people/` и `budget/` — только внутренняя модель; секреты — только в переменных окружения.

## Синхронизация
- Ноутбук: Obsidian, открытый на этом репозитории; git вручную или плагином Obsidian Git.
- Телефон: Obsidian + Obsidian Git (pull/push). Завести задачу агенту = новый файл в `fleet/` из шаблона.
- Запуск агентов с телефона: через веб-интерфейс Cursor; ссылку на запуск вносить в `run_url` задачи.

## Мой день (ориентир)
1. Открыть `DASHBOARD.md` → разобрать «Требует моего решения».
2. Работа стеком: одна задача за раз, остальное держит система.
3. Входящее сырьё — дроп в `inbox/`, агент разнесёт по контурам.
