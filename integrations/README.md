# Интеграции

Чтение — автоматически. Запись во внешние системы — только по явной команде (см. корневой `AGENTS.md`).

| Система | Тип | Доступ | Что делает агент |
|---|---|---|---|
| Jira | on-prem | PAT | чтение: статусы и данные для Ганта по фильтрам направлений (`jira_filter` в `directions/`); запись — по команде |
| Confluence | on-prem | PAT | чтение: контроль актуальности страниц (A9); публикация общекомандной документации — по команде (A10) |
| Внутренняя LLM | endpoint, OpenAI-compatible | API key | обработка internal-контуров (`people/`, `budget/`, файлы с `sensitivity: internal`) |
| Транскрибации | веб + корп. авторизация | уточняется (F-0002) | цель: автозабор в `inbox/transcripts/` |
| Outlook | — | — | ручной дроп писем в `inbox/mail/` |
| Внутренний чат | уточняется (F-0001) | уточняется | исследование API для выгрузки в `inbox/chats/` |
| Telegram | — | — | ручной дроп (с рабочего компьютера доступа нет) |

## Переменные окружения (контракт)
Значения — только на машине пользователя. Никогда не коммитить, не выводить, не передавать в промпты (см. `AGENTS.md`, раздел «Секреты»).

| Переменная | Назначение |
|---|---|
| `INTERNAL_LLM_URL` | base URL внутренней модели |
| `INTERNAL_LLM_KEY` | ключ внутренней модели |
| `JIRA_URL`, `JIRA_TOKEN` | доступ к Jira |
| `CONFLUENCE_URL`, `CONFLUENCE_TOKEN` | доступ к Confluence |
| `TRANSCRIPTS_*` | уточнится по итогам F-0002 |
