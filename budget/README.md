# Бюджет

R&D-бюджет в режиме «гаражной разработки»: чётких фич нет, планирование по принципу оптимального бюджета в условиях неопределённости. Чувствительность — internal (см. `AGENTS.md` этой папки).

- `plan-next-year.md` — формируемая сейчас потребность на следующий год (пять категорий).
- `optimization.md` — параллельный процесс: пересмотр прошлогоднего плана, что готовы сдать в оптимизацию.
- `scenarios/` — сценарные расчёты внутренней моделью (по одной заметке на сценарий).
