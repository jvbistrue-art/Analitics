# Правила контура «Бюджет»

- Всё содержимое этой папки — `sensitivity: internal`.
- Обработка только внутренней моделью (opencode + внутренний endpoint) или локально. Содержимое не отправляется в облачные модели.
- Сценарные расчёты («что если наймём двоих в Q3», «что сдаём в оптимизацию») выполняются здесь же, каждый сценарий — отдельная заметка в `scenarios/`.
- В `DASHBOARD.md` выносится только фаза процесса («идёт сбор потребности», «на согласовании») — без сумм и статей.
