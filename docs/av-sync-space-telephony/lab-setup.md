# Лабораторный стенд

## 1. Целевая архитектура теста

```text
┌───────────────────────────┐         ┌───────────────────────────┐
│ Sender A                  │         │ Receiver B                │
│                           │         │                           │
│ Stimulus / Camera+Mic ────┼──video──► IP / WebRTC / data ───────┼──► Display
│                           │         │                           │
│ Audio (same stimulus) ────┼──voice──► Space telephony (or emu) ─┼──► Speaker
│                           │         │                           │
│                           │         │ Screen+audio recorder ────┼──► capture.mkv
└───────────────────────────┘         └───────────────────────────┘
                                              │
                                              ▼
                                      av_sync_measure
                                      → report.json
```

Ключевой принцип: **измеряем то, что видит и слышит человек на приёме**, а не служебные timestamps внутри сети.

## 2. Минимальный комплект

### Устройства

- 2 клиента видеозвонка (телефоны / десктоп).
- На B: возможность записи экрана с системным звуком.
  - Android: scrcpy + отдельный audio route, или встроенный screen recorder с internal audio.
  - Desktop: OBS (Display Capture + audio output capture).
- На A: плеер стимула или «виртуальная камера/микрофон» с тестовым роликом.

### Связь

- Видео-путь: обычный IP (Wi‑Fi/LTE/5G data).
- Аудио-путь:
  - **lab:** эмулятор задержки;
  - **field:** реальная космическая телефония.

## 3. Эмуляция космической телефонии (для офиса)

Пока нет боевого sat-канала, эмулируйте **только аудио-путь**.

### Вариант A — Linux `tc netem` на аудио-шлюзе

Если голос проходит через выделенный Linux gateway:

```bash
# пример: +500 ms задержки на исходящем интерфейсе аудио
sudo tc qdisc add dev eth0 root netem delay 500ms 20ms distribution normal
```

Снять:

```bash
sudo tc qdisc del dev eth0 root
```

Типовые профили:

| Профиль | delay | jitter | Пояснение |
|---|---|---|---|
| GEO-like | 500–700 ms | 10–40 ms | геостационар |
| LEO-like | 40–80 ms | 10–30 ms | низкая орбита, переменность |
| Stressed | 700 ms | 50 ms + 1% loss | плохой канал + PLC |

### Вариант B — локальный audio delay node

Если приложение позволяет вставить audio insert/effect:

- задерживать только playback/capture PCM на N ms;
- видео не трогать.

### Вариант C — DAW / virtual cable

Sender mic ← Virtual cable ← player with known delay plugin.

Подходит для калибровки метода измерения.

## 4. Полевой стенд (реальный спутник)

Дополнительно зафиксировать в протоколе:

- оператор / тип системы (GEO/MEO/LEO);
- терминал (antenna, UE, handset);
- режим (voice dedicated / VoIP over sat / gateway PSTN);
- SNR / уровень сигнала, если доступен;
- факт подтверждения маршрута (скрин/CDR/SIP Call-ID).

Нельзя считать прогон валидным, если голос мог уйти в обычную сотовую телефонию.

## 5. Запись на приёмнике

### Рекомендуемый профиль OBS / аналог

- Video: 1080p или родное разрешение окна звонка, **30–60 fps**, без переменного frame pacing по возможности.
- Audio: захват **выхода** (what you hear), 48 kHz, mono или stereo.
- Контейнер: MKV/MP4 с аудиодорожкой.

### Чего избегать

- Запись комнаты вторым телефоном «на стол» — появляется акустическая задержка и реверберация.
- Сильного compression записи экрана (портящего вспышки).
- Автозума/кропа окна звонка посередине прогона.

## 6. Калибровка стенда записи (обязательно один раз)

Цель: понять погрешность самого рекордера.

1. На одном ПК локально играть стимул на экране + в наушники/динамики.
2. Записать тем же способом, что будет на B.
3. Измерить offset.

Если локальный loopback даёт, например, `+18 ms`, вычитайте этот bias из полевых измерений:

```text
true_offset ≈ measured_offset - recorder_bias
```

Инструмент поддерживает `--bias-ms`.

## 7. Протокол стенда (заполнять на каждый прогон)

```yaml
run_id: S3-field-001
date_utc: 2026-08-03T12:00:00Z
scenario: S3
sender_client: "app 1.4.2 / Android 14"
receiver_client: "app 1.4.2 / Windows 11"
video_path: "WebRTC over LTE"
audio_path: "space telephony GEO gateway"
audio_delay_emulated_ms: null
compensation: off
recorder: "OBS 30.1, 60fps, desktop audio"
recorder_bias_ms: 18
notes: "antenna clear sky"
capture_file: receiver_capture.mkv
```

## 8. Безопасность и этика

- Не записывать личные разговоры — только тестовый стимул или согласованный скрипт.
- Полевые прогоны через боевые каналы согласовать с владельцем канала.
- В репозиторий класть только анонимизированные отчёты и короткие сэмплы стимула, не сырые звонки пользователей.
