# Практики техдиректора: шаблоны

Минимальный набор для контроля ситуации с техлидами: **видимость** и **сроки**.

## Как внедрять (2 недели)

1. **Неделя 1**
   - Запусти `01-weekly-sync.md` (пн) и Status Close (пт).
   - Попроси каждого техлида заполнить `02-team-status.md`.
   - Договорись: жёлтый/красный риск → сразу `03-risk-escalation.md`.

2. **Неделя 2**
   - Ведите `04-weekly-commitments.md` на каждый Planning Sync.
   - В пятницу сверяйте обещание ↔ факт.
   - Обновляй свою «Карту контроля» 15 минут после пятничного sync.

## Файлы

## Принцип

Ты контролируешь **приоритеты, вехи и решения**.  
Техлиды контролируют **исполнение**.
