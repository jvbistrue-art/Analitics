# Weekly Sync с техлидами

## Понедельник — Planning Sync (30–40 мин)

**Участники:** техдиректор + техлиды  
**Цель:** договориться о результатах недели и рисках

### Повестка

| # | Блок | Время | Правило |
|---|------|-------|---------|
| 1 | Контекст / приоритеты сверху | 5 мин | Только изменения с прошлой недели |
| 2 | Круг по командам | 20–25 мин | По шаблону ниже, без деталей задач |
| 3 | Решения и trade-off | 5–7 мин | Что режем / что двигаем |
| 4 | Фиксация обязательств | 3 мин | Письменно в трекер обязательств |

### Шаблон выступления техлида (2–3 мин)

```
Команда: _______________
1) Цель недели (1–3 результата, проверяемые):
   - 
   - 
2) Уверенность в сроках: 50% / 70% / 90%
3) Главный риск:
4) Блокер (если есть) + от кого нужен ответ:
5) Просьба к техдиру (решение / приоритет / ресурс):
```

### Правила митинга

- Говорим о **результатах**, не о списке задач.
- Если уверенность <70% — это прогноз, не обязательство.
- Новые запросы на митинге не принимаются «втихую»: только через trade-off.
- Всё обещанное фиксируется в `04-weekly-commitments.md`.

---

## Пятница — Status Close (20–25 мин)

**Цель:** сверка факта с обещанием, без наказаний

### Повестка

| # | Блок | Время |
|---|------|-------|
| 1 | Круг: обещали → сдали | 12–15 мин |
| 2 | Что уехало и почему (1 причина) | 5 мин |
| 3 | Что переносим на следующую неделю | 3–5 мин |

### Шаблон выступления техлида

```
Команда: _______________
1) Обещали:
2) Сдали:
3) Не сдали / сдвинули:
4) Причина (выбрать одну основную):
   [ ] Оценка
   [ ] Зависимость
   [ ] Scope creep
   [ ] Качество/баги
   [ ] Ресурс
   [ ] Другое: ________
5) Что меняем на следующей неделе:
```

### После митинга (техдиректор, 15 мин)

- Обновить `05-control-map.md`
- Зафиксировать открытые решения
- Отметить команды в 🟡/🔴 для follow-up
