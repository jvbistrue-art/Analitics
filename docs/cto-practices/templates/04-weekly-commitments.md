## Правила формулировки обязательства

Хорошо:
- «К пятнице API платежей в staging, постман-коллекция приложена»
- «К среде миграция пользователей 100% на проде»
- «К четвергу принято решение: делаем вариант A или B»

Плохо:
- «Продолжаем работу над платежами»
- «Почти готово»
- «В процессе рефакторинга»

Шаблон фразы:
> К **[день]** будет **[результат]** в состоянии **[критерий готовности]**.
